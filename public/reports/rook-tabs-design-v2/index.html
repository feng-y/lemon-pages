分期
一期

Kanban、全部任务、待我评审、chat 的工作区。视图只在 Kanban 的子页面边栏，不与新会话 / 自动化 / Kanban 同级。

二期

我的工作、运行中、收件箱。先有稳定的 assignee 和通知，再加这些视图。

三期

已订阅、全部视图、项目分组与新建项目。等任务量和多项目出现后再上。

工作区只在 chat 的边栏出现；Kanban 和自动化不再重复挂一份工作区。项目是后续对工作区的任务化命名，不会并存两套层级。个人设置与工作区设置都是主导航项，放在主导航底部；工作区设置只对管理员渲染。

视图口径

P1 只做两个直接复用任务数据的视图；带「后续支持」的入口先留在边栏，后面按阶段实现。

全部任务P1

四列看板，全部任务；列内按状态聚合，点卡片进任务页。

待我评审P1

只列审核中且评审人是我；点开直接进评审闸门，通过或打回。

收件箱P2

评审请求、agent 完成、@我的通知流；需要未读状态。

我的工作P2

我创建、我负责或我评审的任务；先定清楚「我的」口径。

运行中P2

进行中且有 agent 在跑；显示 agent、已跑时长、当前步骤。

已订阅P3

我关注的任务及其变更；需要订阅模型。

全部视图P3

视图目录和自定义视图；需要保存视图。

支付P3

按项目过滤的看板；项目是任务分组。

新建项目P3

创建项目并挂任务。

设置入口

两个入口与 新会话 / 自动化 / Kanban 同级，放在主导航底部。个人设置所有成员可见；工作区设置只有管理员渲染，普通成员没有这个入口。

个人设置所有成员

入口是主导航底部的「个人设置」：账号、通知、外观、快捷键。每个成员都能进。

工作区设置仅管理员

成员、Agent、模型、权限、计费。普通成员的主导航不渲染这个入口，不是置灰。

四个视图共用同一套壳和同一份状态：会话里的执行，就是任务页的时间线；任务的来源，就是会话；自动化的每次运行，都是一次会话。
