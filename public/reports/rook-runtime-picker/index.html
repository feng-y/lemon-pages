Runtime 选择器

选择层级为 Runtime → 模型 → 思考强度。左栏选 Runtime，右栏只列它支持的模型，思考强度只给当前模型接受的档位。默认模型来自各 Runtime 的配置，会话开始后 Runtime 锁定。

交互规则

  • Runtime。Pi 可用。Claude Code 和 Codex 显示“未开放”，因为部署镜像没有对应二进制，服务端也只构造了 Pi 执行器。能力表已经备好，开放时只需改 runtimeAvailability。
  • 模型。只列当前 Runtime 支持的模型。Pi 接受全部已启用模型；Claude Code 仅 anthropic-messages 模型；Codex 仅 openai-responses 模型。
  • 思考强度。由 Pi 已安装目录的 getSupportedThinkingLevels 算出，按模型变化。Claude Code 和 Codex 的档位表各自维护。切换模型时 effort 自动收敛到受支持的档位。
  • 默认值。默认模型取自 bilibiliRuntime 的配置；effort 默认 high，模型不支持 high 时取最后一个可用档。
  • 锁定。会话开始后 Runtime 不可改，其他 Runtime 提示“会话已开始，新建会话后可切换”。模型和思考强度仍可调整。
