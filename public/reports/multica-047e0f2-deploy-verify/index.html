B6 缺陷：Stop 后立即发下一轮

可稳定复现：stopped 后约 0.2 秒内提交的新 Run 报 native_context_changed

第一次：Session 1257bae5… 中 Run 9fbd3c30… 被 Stop，状态变 stopped；紧接着的 Run 64437650… 在 23:11:28.266 提交，直接失败 native_context_changed。隔约 20 秒重发的 Run 31d7a36b… 成功返回 OK。

第二次复现：Session dc3212b0… 的 Run f28ec042… 在 23:12:11.052 变为 stopped，下一个 Run 在 23:12:11.237（242 毫秒后）提交，同样失败 native_context_changed。

影响：用户按 Stop 后立刻发新消息会看到错误；稍后重发正常。这是验收不通过项，建议单独修复（对齐 stopped Run 的 native context 与下一 Turn 的预期，或提交时重试/等待上下文收敛），本次未改代码。
