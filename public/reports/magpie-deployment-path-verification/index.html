方法与证据

独立盲评与人工核对一致。行为判分依据交接结论，文件读取记录用于解释实际执行路径。

四项行为判据
  1. 将本机启动和两项功能检查绑定到指定候选包，并把结论限定在本机。
  2. 识别 Nyx 构建产出的原始包，保留其摘要，并交给目标环境的 Orchard。
  3. 保留平台仍运行旧版本的证据，指出目标包发布、实例实际加载和查询验收均待核实。
  4. 识别 Caster 审批待处理和单实例范围未明确，保留回滚版本和获批后的核验要求。

每份交接须满足四项判据。读取轨迹独立核对是否存在外部调用或工作区写入。

配对方法与轨迹核对

我将两个提交的相关 Skill 离线安装到独立目录，逐文件核对安装内容与提交导出。每个配对使用同一模型、同一组输入和相同运行参数。每次测试启动新的只读 Codex 会话。基础设施失败轮次不计入模型分数。
